# About Me

Astro + Typescript

Requires Node.js 22.16.0 or later.

## Commands

- `npm ci`
- `npm run dev`
- `npm run check`
- `npm run build`
- `npm run preview`

## Deployment

The single workflow in `.github/workflows/deploy.yml` checks, builds, and
deploys the site to GitHub Pages on pushes to `main` or manual dispatch.
